# 可执行演示脚本

1. 按USER_GUIDE启动，确认默认本地来源和模型配置安全状态。
2. 用缺少具体型号/场景的任务展示必要补问，再创建HUAWEI MateBook14（鸿蒙版）/大学新生/新生开学/朋友圈任务。
3. 连续展示策略、实际本地取证、实际模型生成、独立核验、当前成稿；打开来源定位。
4. 修改标题与图注，显示导出关闭；保存后显示旧报告stale，重新核验，再下载图文HTML并离线打开。
5. 同产品换出差办公，比较卖点与文案；分别加载小红书图集笔记、公众号分节文章的实际运行记录。说明平台预览为模拟、未发布。
6. 另一型号Pro S任务核对名称/事实/图片全换；D16两图的小红书任务展示缺1张和导出阻断。
7. 用明确synthetic负例展示无依据价格/亲测、冲突、迟到结果等自动测试证据，不能说成实际改过原始资料。

当前客户端公开的浏览器控制API没有连续录屏入口。截图和HTTP记录是各自证据，不能冒充连续Demo视频；正式赛事视频需按上述顺序实际录制，不能靠静态截图拼成实时过程。
