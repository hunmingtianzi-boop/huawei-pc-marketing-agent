# 本机交付 1 · 使用说明

## 运行与素材

安装 Node（本机已用26.0.0验证），在源码目录 `npm ci`，填写本机 `.env.local` 的 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。本次使用现有 `https://api.openai-next.com/v1` 与 `gpt-4.1` 路由。密钥不随源码包交付。`npm run build` 后执行 `npm start -- --port 3210`，打开 http://127.0.0.1:3210/ 。

将已授权的 `华为PC全板块深度知识库_v7` 放在项目根目录，或设置服务端 `LOCAL_KB_ROOT` 为它的绝对路径；保持目录结构。默认 **local · 本地素材 + 实际模型**，不需要ima凭证，不调用ima接口，也不访问CSV内的网络图片链接。菜单显示实际本机可用产品与去重图片数；无资料或图不足会具体提示。只有显式选择live才使用ima原接口和额度。人工synthetic默认关闭，不能冒充真实成稿。

本地读入范围为P1两类主产品目录的产品事实.md、图片索引.csv和原件；没有把全库营销范文作为事实。来源记录保留具体型号、相对文件定位、短摘录、原取证时间和摘要。资料是文件快照，不代表官网当日信息。报价/权益没有有效支持时不写。

## 一次完整任务

1. 选择明确产品，填写人群、场景、平台、内容目标；信息不足时先补必要字段。
2. 执行任务。实际流程依次形成策略、读取事实和图片、调用模型生成、规则校验、再独立调用模型核验。失败/冲突/图片不足会保留原因，不能导出完整成稿。
3. 查看策略的卖点顺序和事实依据，再看当前平台的模拟预览。小红书是首图图集和笔记，朋友圈是社交动态与配图，公众号是标题导语及分节长文内嵌图。所有预览未发布，不伪造互动量。
4. 可以编辑标题、导语、正文、CTA、标签、图注、选图及顺序/插入位置。修改立即关闭导出；保存会递增版本，让旧核验失效，再点重新核验。修改场景/平台后重新规划生成，不能把同一稿直接换皮视为已适配。
5. 当前版本通过后复制文本、下载Markdown，或下载图文HTML。HTML内嵌当前选图，离线浏览器打开即可审阅；不是平台发布接口或一键导入协议。图片原比例保留，不以重复图补数。

公众号2–4张，小红书3–6张，朋友圈1–3张。本机MateBook D16 2024只有2张时，小红书任务应停止，用户可换素材足够的型号或选择符合素材数的平台。不能上传外部图来绕过来源限制。

## 异常与恢复

- 型号不明确：使用产品列表里的完整名称，区别鸿蒙/Windows版本、Pro/Pro S等。
- 来源冲突/无依据断言/缺少条件：按核验定位修改或重新生成；不要把阻断项删除成“已通过”。
- 模型请求超时/限流/格式错误：保留失败记录，检查服务配置后重试。没有固定样稿兜底；一次模型生成可能因无依据表述被阻断。
- 修改期间旧请求完成：服务端只接纳当前版本和operationId，旧结果不会恢复导出。
- 图文导出失败：先重验，图片缓存损坏会撤销原通过结果。

`重新取证并执行`从选定来源重新读入；`使用当前取证重新生成`可复用同任务24小时内的有效快照并逐图检查字节，保留原取证时间。换产品不继承原产品证据。

## 本机安全与交付边界

运行记录和原件位于忽略的 `.local-data/`，证据日志在 `.local-evidence/`；凭证文件0600。源码包不含原始全库、密钥、运行私有响应、node_modules或构建缓存。新机需要自行取得有权使用的同一资料目录。HTML成稿含所选产品图片，仅用于有权限的本地审阅；不将这些私有示例并入公开源码。

应用适用于本机单用户、单Node进程，绑定127.0.0.1；未提供公网认证、多租户隔离或多进程存储锁。尚未公开部署、推送、赛事提交或接通任何平台发布账号。海报不在首版承诺内。来源local按用户本轮授权交付，不把它声明为赛题所需的fresh ima运行证明。
