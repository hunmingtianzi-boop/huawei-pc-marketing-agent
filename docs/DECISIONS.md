# 决策记录

以下是本开发包提出的初始实施基线。启动后由主控根据现有项目和实测结果确认或修订，不伪称用户逐条确认。

| 编号 | 决策 | 依据与用途 | 状态 |
| --- | --- | --- | --- |
| D01 | 三个主对话按阶段顺序推进 | 分离接口确认、并行实现、独立验收；每轮通过文件交接 | 初始基线 |
| D02 | 一个主控，最多三个同时开放子线程 | 当前项目可以分成接入、工作流、界面；控制协调成本 | 初始基线 |
| D03 | 写入任务使用不同 worktree | 聊天与子线程不提供默认文件隔离；保证共享文件有唯一集成者 | 初始基线 |
| D04 | 先真实探测 ima，再冻结内部契约 | 官方包与手册字段存在差异，媒体链接未必可用 | 必须实测 |
| D05 | TypeScript + Next.js/Node 单应用 | 统一前后端类型与部署，便于调用 CJS；已有合适项目可沿用 | 可按现有项目调整 |
| D06 | 应用采用有状态的可核验工作流 | 所有事实/图片有依据，冲突停稿，修改后重新核验 | 初始基线 |
| D07 | 第一版支持公众号、小红书、朋友圈 | 对应核心现场检查；海报作为后续覆盖项单独标记 | 初始范围 |
| D08 | 不固定 Codex 或运行模型名称 | 实际版本、账号和提供商未验证；由本机可用能力决定 | 初始基线 |
| D09 | 用文件保存状态、任务与决策 | 下一对话可恢复，不依赖旧聊天或子线程完整历史 | 初始基线 |

后续每项新决定记录：事实依据、可选路径、选定做法、影响范围、关联提交。日常日志和完整工具输出不放在此处。
