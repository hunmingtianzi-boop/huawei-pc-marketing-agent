# 中断后恢复当前阶段

读取 AGENTS.md、docs/STATUS.md、docs/TASK_BOARD.md、docs/DECISIONS.md 和当前阶段对应的 prompts 文件，再核对实际 Git 根、分支、提交与未提交修改。

先确认哪些已有结果能由代码和运行证据支持；不要依赖旧聊天、假定已完成或重新做完整调研。保留用户与其他任务的改动。

检查任务板中的子任务、worktree、返回提交与尚未集成的工作；已结束子线程不假装仍在运行。继续最接近完成的必要任务，修复实际阻塞，按原验收标准推进。

如果接口、契约或依赖已经改变，主控先更新共享事实再重新分派受影响任务。只在缺少真实凭证、外部权限或重大需求冲突时向用户提出一个具体问题，同时完成不受影响的工作。

本轮结束时更新状态与交接，说明实际完成、证据和下一步。
